# UNICEF Practice Repository

This repository was created to practice the GitHub contribution workflow.

## Project Description

The main purpose of this project is to learn how to contribute to open-source projects using GitHub.

## Objectives

- Create and manage GitHub issues.
- Work with different branches.
- Create pull requests.
- Review and merge changes.

## Conclusion

This project demonstrates the basic GitHub contribution cycle, including creating an issue, making changes, submitting a pull request, and merging it.
